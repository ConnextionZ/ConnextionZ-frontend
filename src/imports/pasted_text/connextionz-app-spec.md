Transform ConnextionZ from a static prototype into a fully interactive, high-fidelity application. The app should feel like a real product that users can explore rather than a collection of mockups. Every major screen should contain realistic content, interactive elements, and natural navigation. Avoid placeholder screens or dead ends wherever possible.

Home Feed

When the app opens, immediately display a populated Discover Feed featuring realistic, full-screen vertical videos with infinite scrolling.

Each video should be fully interactive. Users should be able to:

Swipe vertically through videos
Tap to pause or resume playback
Like videos
Comment
Share
Save
Open the creator's profile
Tap hashtags
Tap the audio used in the video
Open the comments section
View collaboration statistics
Press the signature Collab Button

Every video should feel like a real social media post with realistic creator information, captions, engagement counts, and interactive UI.

Interactive Collab Button

Every video in the feed should include the signature electric-blue Collab Button.

When pressed:

Play the complete Collab Button animation (spark → vibration → explosion → dissolve → reconstruction).
Open the collaboration request sheet.
Allow users to send collaboration requests.
Display realistic confirmation states.
Show whether the creator is currently accepting collaborations.

The button should feel like the defining interaction of the platform.

Trending Sounds

Create a dedicated Trending Sounds page.

This page should display a list of popular audio tracks currently being used throughout ConnextionZ.

Each sound should include:

Album artwork or sound thumbnail
Sound title
Original creator
Number of videos using the sound
Total plays
Trending rank
Growth indicator
Save Sound button
Use This Sound button

Clicking any sound should open a dedicated sound page displaying every video created with that audio.

From this page users should be able to:

Watch videos using the sound
Open creator profiles
Collaborate with creators using the sound
Save the sound
Share the sound

Previous messages

Message reactions

Include action buttons for:

Video Call
Voice Call

The messaging experience should feel polished and production-ready.

Collaboration Requests

Create a dedicated Collaboration Requests page.

This page should function similarly to friend requests but specifically for collaboration opportunities.

Each request card should display:

Creator profile picture
Username
Verification badge (if applicable)
Collaboration Score
Mutual collaborators
Collaboration category
Personal message
Budget (if provided)
Timeline
Local or Remote indicator
Time sent

Each request should provide two clear actions:

✅ Accept

❌ Ignore

Accepting a collaboration should immediately trigger the complete "🚀 Your collaboration is officially live!" celebration sequence, including the exploding notification, particle effects, avatar celebration, and opportunity unlock animation.

Ignoring a request should remove it with a clean, subtle animation.

Overall Goal

Design ConnextionZ so that it feels like a polished, production-ready social platform with real content, real navigation, and meaningful interactions. Users should be able to naturally discover creators, explore trending content, browse sounds, exchange messages, manage collaboration requests, and navigate between connected experiences without encountering placeholder screens. The prototype should convincingly demonstrate how ConnextionZ transforms every piece of content into a potential collaboration, job opportunity, or business relationship.
